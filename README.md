# Software Engineering & Machine Learning Labs

This repository contains practical experiments in software repository analysis, natural language processing, embeddings, neural networks, and Transformer-based machine learning.

## Labs

- [Software Repository Mining (Lab 1)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab1/README.md) — Analyzed open-source repositories by mining source code and commit history.

- [Source Code Data Processing (Lab 2)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab2/README.md) — Processed and cleaned mined repository data to prepare it for further analysis.

- [Text Tokenization (Lab 3)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab3/README.md) — Explored character, word, and subword tokenization techniques for software engineering text.

- [Token Embeddings (Lab 4)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab4/README.md) — Created numerical representations of tokens and performed similarity analysis using embeddings.

- [Neural Network Architecture Comparison (Lab 5)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab5/README.md) — Compared different neural network architectures and their performance.

- [Phishing Email Detection with LSTM (Lab 6)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab6/README.md) — Built and trained an LSTM model to classify emails as legitimate or phishing.

- [Phishing Email Detection with DistilBERT (Lab 7)](https://github.com/SamirChowdhary24/CSET456Lab/blob/main/lab7/README.md) — Fine-tuned a pre-trained Transformer model and compared its performance with the LSTM approach.
