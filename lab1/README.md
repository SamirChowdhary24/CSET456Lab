# Lab 1: Software Repository Mining

## Repository Selected

FastAPI  
GitHub URL: https://github.com/fastapi/fastapi

## Objective

The objective of this lab is to mine and profile an open-source software repository. This includes collecting repository inventory, creating a file-level dataset, mining Git history, and recording repository-level observations.

## Folder Structure

- `src/` contains the source code written for this lab.
- `data/` contains datasets generated during the lab.
- `output/` contains final output files for the lab.
